# Notes

A simple note-taking web app built with React + Vite + TypeScript. Notes are stored in the browser's localStorage, so no backend is required.

## Features

- Create, edit, and delete notes
- Search notes by title or content
- Persist notes in localStorage

## Quick start

1. Clone the repository
2. Install dependencies:

   npm install

3. Start the dev server:

   npm run dev

4. Build for production:

   npm run build
